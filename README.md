## სწავლის შედეგი 2 — TypeScript-ის საბაზისო კონსტრუქციები

### 2.1 — ტიპიზებული ცვლადები

შექმენით:

- `string` ტიპის პროდუქტის სახელი;
- `number` ტიპის ფასი;
- `boolean` ტიპის მარაგის სტატუსი.

გამოიტანეთ ყველა მნიშვნელობა კონსოლში.

### 2.2 — ფუნქცია და დასაბრუნებელი ტიპი

შექმენით `getProductInfo` ფუნქცია, რომელიც პარამეტრებად მიიღებს პროდუქტის მონაცემებს და დააბრუნებს ფორმატირებულ ტექსტს.

### 2.3 — if/else პირობა

შექმენით `getDiscount` ფუნქცია, რომელიც ფასის მიხედვით დააბრუნებს:

- `"10% discount"`
- `"5% discount"`
- `"No discount"`

### 2.4 — მასივი და ციკლი

შექმენით 5 პროდუქტისგან შემდგარი `string[]` მასივი და `for` ციკლის გამოყენებით გამოიტანეთ თითოეული ელემენტი ინდექსთან ერთად.

შექმენით `TOrder` type alias შემდეგი ველებით:

ორივე ობიექტის ინფორმაცია გამოიტანეთ კონსოლში.

## სწავლის შედეგი 4 — კლასები და OOP

### 4.1 — Employee კლასი

შექმენით `Employee` კლასი შემდეგი თვისებებით:

- `firstName`
- `lastName`
- `position`
- `yearsOfExperience`

### 4.2 — ობიექტის შექმნა

შექმენით `Employee` კლასის ობიექტი და გამოიტანეთ მისი ინფორმაცია კონსოლში.

### 4.3 — მემკვიდრეობითობა

შექმენით `Developer` კლასი `Employee` კლასის მემკვიდრეობით (`extends`) და დაამატეთ `getTechStack()` მეთოდი, რომელიც დააბრუნებს ტექნოლოგიების სიას.

### 4.4 — კლასის მეთოდი

`Employee` კლასში დაამატეთ `getFullInfo()` მეთოდი, რომელიც დააბრუნებს თანამშრომლის სრულ ინფორმაციას ფორმატირებული ტექსტის სახით.

გამოიძახეთ ეს მეთოდი როგორც `Employee`, ისე `Developer` კლასის ობიექტებისთვის.
